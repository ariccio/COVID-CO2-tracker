# Continuation Prompts

Handoff prompts for resuming work after context limits or session interruptions.

## Purpose
- Enable seamless work continuation
- Preserve critical context
- Guide next agent to pick up where previous left off

## Structure
- Current state summary
- Next steps clearly defined
- References to relevant files/docs
- Decision context

## When to Create
- Approaching context limit
- Natural breakpoint in complex work
- Need to switch to different task temporarily
