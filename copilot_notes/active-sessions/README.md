# Active Sessions

Current work-in-progress notes and context for ongoing development sessions.

## Purpose
- Track active development efforts
- Maintain context across session interruptions
- Coordinate parallel work streams

## Usage
- Create session file: `YYYY-MM-DD-descriptive-task-name.md`
- Update as work progresses
- Move to work_reports/ when complete

## Retention
- Active: During development
- Archive: After session completion and report generation
